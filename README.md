A little duckling in a captain's hat, wings spread with delight, sailing a red paper boat across a rain puddle that reflects a rainbow — a small, specific moment of pure joy, painted in warm watercolour light. The program decodes the image the repository holds and writes it to /output/entry.png, byte for byte, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
